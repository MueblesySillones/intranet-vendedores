Kit de recuperación

Genera un solo archivo con todo lo necesario para retomar el control del sitio si esta computadora se pierde: qué cuentas hay, qué desbloquea cada una, tu clave de publicación y el paso a paso.

Se guarda cifrado con una contraseña. Para abrirlo alcanza con hacerle doble clic: se abre en cualquier navegador, sin instalar nada.

Ya te generé una clave segura. Podés dejarla o escribir la tuya. Anotala junto con el archivo: sin ella no se puede abrir.

⚠️ Si perdés esta contraseña no hay forma de recuperar el archivo. Guardá el kit en dos lugares distintos.
